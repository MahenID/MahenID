## 👨‍💻 About Me

I'm **Mahen**, an IT student at **ITB STIKOM Bali**, Indonesia,
with an interest in building practical web and mobile applications.

My projects span software license management, Flutter applications,
restaurant workflows, and a personal Linux home server.
Through my internship at **PT Central Saga Mandala**, I've worked on
connecting system requirements with application design and implementation.

- 🌐 Building web applications with **Laravel and Next.js**.
- 📱 Developing mobile applications with **Flutter and Firebase**.
- 🧠 Learning **Kotlin, image classification, YOLO, and on-device ML integration**.
- 🐧 Exploring **Ubuntu Server, WSL, containers, and local networking**.
- 🎨 Interested in **UI/UX and clear, usable application flows**.
- 🔧 Hands-on experience with **PC assembly, upgrades, and troubleshooting**.

> My curiosity goes beyond the interface: I enjoy understanding the
> application, the database, and the machine running it.

## 🚀 Selected Projects

### 💼 Software License Management System

A web-based information system project for **PT Central Saga Mandala**,
focused on organizing software licenses and renewal workflows.

- Software and license records.
- Role-based access for internal users.
- License requests and approval workflows.
- Expiration reminders and reporting.

**Stack:** Laravel · Next.js · MySQL · Podman

### 🌱 Florapp

A plant marketplace application built with **Flutter and Firebase**.

- Authentication and email verification.
- Product browsing and selling interfaces.
- Buyer and seller experiences within one account.
- Ongoing development of marketplace and transaction features.

**Stack:** Flutter · Dart · Firebase Authentication · Cloud Firestore

### 🏠 Mahendra HomeLab

A personal portfolio and local server learning project.

- Portfolio pages for skills, projects, and contact information.
- Ubuntu Server setup on repurposed laptop hardware.
- Local network hosting and connectivity troubleshooting.

**Stack:** HTML · CSS · JavaScript · Ubuntu Server
